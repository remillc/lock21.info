Page 404 : quatre visuels

Des maquettes pour le TODO #86, avec les couleurs, les polices et les formes du site. Le contenu est le même dans les quatre : seul le visuel change.

Ambiance

  • L’instrument de plongée du site (E2) : ordinateur, carnet, gabarit de profondeur.
  • L’idée : « hors du relevé », le visiteur est descendu là où rien n’est numérisé.
  • Un ton léger de plongeur, une phrase. L’orange seulement pour le 404.

Informations

  1. Le constat, en une ligne.
  2. L’adresse demandée, en petit.
  3. Trois sorties : accueil, modèle 3D, découpage du site.
  4. Une recherche dans la page.
